# Roadmap & Future Features (TODO)

This list captures potential enhancements and new features for future development.

---

## 1. Learning & Pedagogy

- [ ] **Stroke Order Diagrams / Animations**
  - Add optional stroke order SVG animations or static diagrams shown during pause, on-demand, or after an error.
  - Useful for learners who are practicing handwriting alongside reading.
- [ ] **Romaji-to-Kana Reverse Mode**
  - Prompt with romaji sound (e.g. `kyo`), test ability to identify or draw/select the corresponding kana character.
- [ ] **Custom Deck Builder & Tagging**
  - Allow users to manually star/tag specific kana and create custom practice decks outside the preset groups.
- [ ] **Audio Drill Mode (Listening Only)**
  - Hide the visual kana card, play the Japanese pronunciation, and have the user type what they heard.

---

## 2. Audio & Multimedia

- [ ] **Studio Human Voice Audio Pack**
  - Bundle high-quality pre-recorded human native speaker audio clips as an alternative to the browser's Web Speech API synthesizer.
- [ ] **Audio Volume & Pitch Slider**
  - Provide fine-grained volume controls for both synthesized speech and feedback chimes.

---

## 3. Analytics & Visualization

- [ ] **Multi-Week Historical Trend Charts**
  - Interactive line charts plotting daily accuracy, CPM, and time spent over weeks and months.
- [ ] **Session History Log**
  - View timestamps and detailed stats for previous practice sessions.
- [ ] **Export to CSV / Anki**
  - Allow exporting stats or custom weak-card decks directly into Anki `.apkg` or CSV format.

---

## 4. UI / Mobile Enhancements

- [ ] **Mobile Virtual Keypad**
  - An optional minimalist on-screen romaji / kana keypad optimized for fast smartphone drills without triggering mobile keyboard layout jumps.
- [ ] **Theme Accent Customization**
  - Allow selecting custom accent color themes (e.g. indigo, emerald, amber, rose) in addition to the default crimson.
- [ ] **Keyboard Layout Remapping**
  - Support for Dvorak, Colemak, or AZERTY keyboard layouts if specific keystroke quirks occur.
